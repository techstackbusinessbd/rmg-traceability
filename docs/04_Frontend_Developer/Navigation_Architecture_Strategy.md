# Navigation Architecture Strategy
**Role:** Frontend Developer / UI/UX Designer
**Project:** RMG Traceability Software
**Status:** Approved for Implementation

---

## 1. Introduction
A clean and intuitive navigation structure is critical for Enterprise Software. Poorly nested menus confuse users, especially factory floor operators using tablets. This document outlines the strict rules for the Topbar and Sidebar components.

---

## 2. Top Bar (Navbar) Strategy
The Topbar must be completely clean and free of any Module Navigation Links. It serves only as a global utility bar.

**Elements allowed in the Topbar:**
1. **Hamburger Menu Toggle:** Only visible on Mobile/Tablet screens to open the sidebar.
2. **Breadcrumbs (Left):** Dynamic breadcrumbs showing the current page (e.g., `Admin / Master Data / Buyers`).
3. **Global Search (Center/Right):** A search bar (or magnifying glass icon) to quickly find a PO or Carton across the system.
4. **Notifications (Right):** A bell icon showing unread system alerts (e.g., "DHU threshold crossed on Line 2").
5. **Theme Toggle (Right):** Sun/Moon icon to switch between Light and Dark mode.
6. **User Profile Dropdown (Far Right):** Shows the user's avatar/name. Clicking it reveals "My Settings" and "Logout".

---

## 3. Left Sidebar (Main Navigation)
The Left Sidebar is the primary navigation hub. 

### 3.1. Maximum 2 Levels Rule (No 3rd Level Menus)
To ensure touch-friendliness on Tablets and to prevent "dropdown fatigue", the sidebar is strictly limited to 2 levels.

- **Level 1 (Module Group):** e.g., "Master Data", "Sewing", "Quality Control". Clicking these does *not* load a page; it simply expands the accordion to show Level 2.
- **Level 2 (Page Link):** e.g., "Buyers", "Styles", "Purchase Orders". Clicking these navigates the user to that specific page.

*Forbidden Example (Do NOT do this):*
❌ Master Data -> Factory Setup -> Sewing Lines
*(This is a 3-level deep menu. It is hard to click on touch screens.)*

### 3.2. How to Handle Sub-entities (Alternative to 3rd Level)
Instead of deep nesting in the sidebar, use **In-Page Tabs**.
- **Correct Approach:** Create a "Factory Setup" page in Level 2. When the user clicks it, the page opens. Inside the page, have Horizontal Tabs at the top: `[General] [Sewing Lines] [Packing Stations]`.

### 3.3. Dynamic Menu Rendering
The sidebar must not hardcode its links. It must be generated by checking the user's permissions.
```jsx
// Example Pseudo-code
{user.permissions.includes('view_menu_qc') && (
   <SidebarItem title="Quality Control" link="/qc/dashboard" />
)}
```
If a Sewing Operator logs in, their sidebar should automatically shrink to show ONLY the "Sewing Input" and "Sewing Output" menus.
